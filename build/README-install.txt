Bench.

Beta. First start asks for your name and work email, then offers the
Microsoft 365 sign-in (skippable; the button waits in Settings).

The photographs ship inside the installer. Settings > Look picks which
libraries rotate: Alps, Tropics, Urban, Monochrome, Pacific Northwest, Desert,
Brutalist, Italian coast, Canada, Autumn, Gothic. A new picture every 20 minutes
by default; Settings changes the pace.

Shared board: Settings > This machine > Choose a shared folder, then restart.
Everyone pointing at the same folder sees the same list. Your hours, sign-ins
and settings stay in your own Windows profile.
